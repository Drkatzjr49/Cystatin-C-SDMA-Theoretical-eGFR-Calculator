# Cystatin-C-SDMA-Theoretical-eGFR-Calculator
This contributes to medicine because it introduces an investigational, creatinine-free dual-marker eGFR model (DFM-SC v0.2) pairing symmetric dimethylarginine (SDMA) and cystatin C to reduce confounding from muscle mass, diet, and tubular secretion. By reporting single-marker estimates alongside inter-marker concordance and a 95% model interval.
